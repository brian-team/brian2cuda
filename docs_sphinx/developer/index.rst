Developer's guide
=================

This section is intended as a guide to how Brian2CUDA functions internally for
people developing Brian2CUDA itself, or extensions to it. It may also be of
some interest to others wishing to better understand how Brian works internally.

CUDA-specific topics build on Brian2's developer documentation for `code
generation <https://brian2.readthedocs.io/en/stable/developer/codegeneration/index.html>`_
and `standalone implementation
<https://brian2.readthedocs.io/en/stable/developer/standalone.html>`_.
